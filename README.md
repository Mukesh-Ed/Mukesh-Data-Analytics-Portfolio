# Mukesh N. — Data & AI Portfolio

Personal portfolio for Mukesh N., a B.Sc Computer Science graduate from VLB Janakiammal College of Arts and Science, Coimbatore (CGPA 8.0).

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Gemini AI

Copy `.env.example` to `.env` and set `GEMINI_API_KEY`. The key is used only by the server and is never bundled into the browser.

## Contact form

The portfolio contact form sends enquiries to `n.mukesh8072@gmail.com` through Gmail SMTP. Create a Gmail App Password and set the values in `.env`. A normal Google API key cannot authenticate Gmail SMTP.
